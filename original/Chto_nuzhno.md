# Что нужно на компьютере

1. **PostgreSQL** (сервер запущен).  
2. **pgAdmin**.  
3. Пароль пользователя **`postgres`** — тот, который задали **при установке** PostgreSQL (на каждом ПК свой).  
4. Локально: Host `localhost`, Port `5432`.
